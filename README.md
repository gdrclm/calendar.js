# calendar.js

Календарь с событиями на чистом HTML, CSS и JavaScript — без сборки и зависимостей.

**Демо: [gdrclm.github.io/calendar.js](https://gdrclm.github.io/calendar.js/)**

## Возможности

- Сетка месяца с понедельника, 5 или 6 строк, дни соседних месяцев приглушены
- Перелистывание месяцев и годов вперёд и назад, кнопка «Сегодня»
- Весь календарь помещается на один экран, без прокрутки страницы
- Выбор дня мышью или касанием
- Быстрое создание события: кнопка «+» в углу дня или двойной клик по дню
- Прошедшие дни приглушены, сегодняшний день подсвечен
- Поиск событий по названию (`/` — фокус в поле поиска)
- Цветовые категории событий: работа, личное, учёба, важное
- Навигация по дням стрелками, `Home`/`End` — начало и конец недели, `N` — новое событие
- Подтверждение удаления и отмена удаления в уведомлении
- Уведомления о сохранении, обновлении и удалении событий
- Создание события во всплывающем окне: название, дата, время, категория, описание
- Редактирование и удаление события по клику на него
- Список событий дня в том же окне — удобно на узких экранах
- Автоматическое сохранение в `localStorage` (ключ `calendar-events-v1`) и восстановление при загрузке
- Компактный мобильный режим: модальное окно-«шторка», уменьшенные ячейки

## Запуск

```bash
npm start
```

Откроется статическая страница через [`serve`](https://www.npmjs.com/package/serve); достаточно и любого другого статического сервера, например `python3 -m http.server`.
