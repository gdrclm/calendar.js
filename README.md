# calendar.js

Календарь с событиями на чистом HTML, CSS и JavaScript — без сборки и зависимостей.

**Демо: [gdrclm.github.io/calendar.js](https://gdrclm.github.io/calendar.js/)**

## Возможности

- Сетка месяца с понедельника, 5 или 6 строк, дни соседних месяцев приглушены
- Перелистывание месяцев вперёд и назад с переходом через год и кнопка «Сегодня»
- Выбор дня мышью или касанием
- Создание события: название, дата, время, описание
- Редактирование и удаление события по клику на него в календаре или в списке дня
- Список событий выбранного дня под формой — удобно на узких экранах
- Автоматическое сохранение в `localStorage` (ключ `calendar-events-v1`) и восстановление при загрузке

## Запуск

```bash
npm start
```

Откроется статическая страница через [`serve`](https://www.npmjs.com/package/serve); достаточно и любого другого статического сервера, например `python3 -m http.server`.
